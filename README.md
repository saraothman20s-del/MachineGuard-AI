# MachineGuard AI

AI-powered Predictive Maintenance system that predicts potential machine failures using Machine Learning.

## 🚀 Live Demo

[Try MachineGuard AI](https://machineguard-ai-csstkwdukzlea3txca4umn.streamlit.app/)

## 🛠️ Technologies

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Joblib
- Random Forest

## 📌 Project Description

MachineGuard AI is a predictive maintenance application designed to help identify the risk of machine failure based on machine and operational data.

The application uses a trained Random Forest machine learning model and provides predictions through an interactive Streamlit web interface.

## ⚙️ Deployment

The application is deployed using Streamlit Community Cloud.

## 📂 Project Files

- `app.py` — Streamlit application
- `predictive_maintenance_rf.pkl` — Trained Random Forest model
- `scaler.pkl` — Feature scaling object
- `encoder.pkl` — Categorical feature encoder
- `numeric_features.pkl` — Numeric feature information
- `threshold.pkl` — Prediction threshold
- `requirements.txt` — Required Python libraries
